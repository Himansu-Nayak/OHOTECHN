## 1. Executive Overview & Methodology

This forensic inventory catalogs the complete database architecture of the OHO TECH platform. The data structures support a production turnkey enterprise ecosystem comprising an e-commerce catalog of 28 software products, self-hosted UPI checkout, licensing and device activation, multi-channel CRM (Meta WhatsApp Cloud API & email outbox), customer helpdesk support tickets, and an AI advisory engine.

### Verification Status & Scope Distinction
* **Source-Code-Derived Findings (Verified):** All table structures, column definitions, JPA annotations, constraints, cascade rules, and entity relationships have been verified from the compiled Java 21 / Spring Boot 4.1 entity models (`com.ohotech.backend.entity.*`) and incremental SQL migrations (`backend/src/main/resources/schema_update_*.sql`).
* **Entity & Table Count Reconciliation:** The repository contains exactly 55 Java files in `com.ohotech.backend.entity`. Forensically, **38 are `@Entity` persistent classes** that map 1:1 to the 38 database tables, and **17 are domain `enum` types** mapped directly as `VARCHAR` columns via `@Enumerated(EnumType.STRING)`. There are **37 JPA repository interfaces**; all entities have dedicated repositories except `OrderItem`, which is managed as a cascaded aggregate collection under `OrderRepository`.
* **Live Database Fact Verification:** Because live VPS database access is decoupled from local read-only development environments, the actual live production PostgreSQL schema on the Hostinger VPS is currently **unverified**. Row counts and live constraint catalog states must be validated using the safe, read-only inspection script before executing any migration.
